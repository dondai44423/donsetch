# README artwork

The README's noir identity: vermilion `#E52B31`, charcoal `#111114`, and warm ivory `#F2E7D3`. Generated illustrations use a 1930s screenprint/linocut treatment; technical labels remain plain and legible.

| Asset | Use | Dimensions |
|---|---|---|
| `masthead.webp` | Main poster with the original pipe-smoking don and title | 2172 × 724 · 3:1 |
| `tools.webp` | Document, search, map, and camera illustration | 2172 × 724 · 3:1 |
| `emblem.webp` | Standalone mascot seal, with transparency outside the emblem | 1254 × 1254 · 1:1 |
| `fetch-route.svg` | Editable, simplified technical route map | 1040 × 660 |

The three illustrations were generated with the built-in image generation tool using the supplied red/black crime-poster reference for mood. The mascot is original artwork. The SVG is authored directly so technical text and connections can be maintained without regenerating an illustration.

Keep the distinction between artwork and technical claims: the prose and fetch-crate documentation own behavior. No scripts, fonts, external images, or animation are required by the SVG.
